# qu投

BOSS 直聘求职助手：支持关键词组筛选、屏蔽词、自定义招呼、岗位城市替换和定时投递。所有筛选在本地完成。

## 安装

1. 点击本页 **Code → Download ZIP**，下载后解压。
2. 打开 `edge://extensions/`（Chrome 用 `chrome://extensions/`），开启**开发者模式**。
3. 点击**加载解压缩的扩展**，选择解压后包含 `manifest.json` 的文件夹。

## 使用

登录 BOSS 直聘并打开职位列表，点击 **qu投 → 设置**，保存筛选条件与招呼内容，再点**开始全自动**。**仅分析岗位**只筛选，不发送。

自定义招呼请先关闭 BOSS 自带的自动招呼；定时投递可设置开始时间、多个职位列表及各自人数，执行时需保持浏览器打开、账号已登录。

## 本地开发

安装 Node.js 后运行 `npm ci`；`npm run check` 检查代码，`npm test` 运行离线测试，`npm run package` 生成安装包和 GitHub 源码包。直接安装无需运行这些命令。
